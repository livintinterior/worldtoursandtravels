This folder is reserved for standalone icon assets.

All icons currently used on the site (services, fleet specs, why-choose-us,
social links, etc.) are hand-written inline SVG directly in the HTML —
this keeps the site to zero icon-font/sprite HTTP requests and lets each
icon inherit `currentColor` for easy theming.

Drop SVG files here if you'd prefer to reference icons as `<img>` files or
build a sprite sheet instead.
